# 编辑器

> 适用：编辑器开发（模式/数据流/预览与跨区定位/快照/图片/表情/图床/粘贴）。按需，写操作协议见 12。

## 五种模式

发帖 / 评论 / 回复评论 / 编辑帖子 / 编辑评论，通过 `EditorType` 枚举区分，URL 绑定见 `EditorSubmitHelper._buildUrl()`（`lib/pages/editor/editor_submit.dart`）。

## 数据流

```
PageFetcher 提取 formhash/hash/uid → 编辑器初始化
  → 用户编辑 → 提交 → API（只做纯提交，不做 fetch）
  → parseSubmitResponse() 统一解析 → SnackBar 结果
```

API 层重构后就地：旧架构 API 自己做 fetch，新架构 API 只提交，formhash 由编辑器统一传入。

## 工具栏（数据驱动 + 模板项）

工具栏项的唯一数据源是 `assets/config/toolbar.json` 的 `items` 段（JSON 读取失败时兜底
`config/toolbar_config.dart` 的 `allToolbarItemConfigs`）；`BBCodeToolbar` 渲染、编辑器快捷键、
设置页排序/显隐全部从此派生（docs/07 #9）。

工具栏项分两类：

| 类型 | 判定 | 行为 | 例 |
|---|---|---|---|
| **模板项** | `data.template` 非空 | 用文本模板包裹选中文字 | `[b]${selectText}[/b]` |
| **复杂项** | 有对应 `ToolbarAction` | 弹窗 / 面板 / 上传 | 图片、表情、链接、颜色、字号… |

模板项字段：`template`（含 `${selectText}` 占位符，见 `kSelectTextToken`）、`label`（按钮文字）、
`group`（分隔线分组：相邻两项分组不同才画线）、`block`（无占位符时按块级插入，用于 `[hr]`/表格骨架）。

应用逻辑统一在 `BBCodeController.applyTemplate`：

- 有选中 → 选中文本（trim 后）替换 `${selectText}`，整体替换选区，光标落在末尾
- 无选中 → `${selectText}` 置空，光标落在原占位符处（`[b]|[/b]`）
- `block` 且无占位符 → 走 `insertBlockTag`（必要时补换行）

**用户自定义**：设置 → 编辑器设置 → 工具栏排序可新增/编辑/删除。自定义模板以
`ManagedItem.data` 存进 `toolbar_items`，复用同一套排序/显隐/快捷键。约束：内置项不可删
（下次同步会还原）、复杂项不可编辑（由代码实现）、仅模板项可编辑。重置默认会保留自定义项。

**分发**：`BBCodeToolbarController.onAction(id)` 与 `EditorToolbarIntent(id)` 一律按 **item id**
派发（模板项不是枚举成员），编辑器 `_handleToolbarItem` 据 id 决定走模板还是复杂动作
（`_handleToolbarAction`）。回归测试：`test/toolbar_template_test.dart`。

**末尾固定按钮**：渲染时在所有可配置项之后**固定追加一个「设置」按钮**
（伪 id `kEditorSettingsId`，打开 `/settings/editor`），**不受工具栏设置影响**（不可排序/隐藏）；
因此即使所有项都被隐藏，工具栏仍会渲染。它不在 `allToolbarItemConfigs` / `toolbar.json` 中。

**新增的两个复杂项**：「编辑历史」（`editHistory`，打开快照历史页 `/editor/history`）与
「导入MD」（`mdImport`，Markdown → BBCode 底部面板）。它们与其它项一样可排序/隐藏。

## 预览与跨区定位（锚点）

预览**逐锚点渲染**：`bbAnchors(source)` 把源码切成锚点（顶层块 ∪ 空行分段 ∪ 整行加粗标题），编辑区与预览区**共用同一份锚点表**，下标即对应关系；预览给每个锚点一个 `GlobalKey`，位置靠 `findRenderObject() → localToGlobal` **现场读**（不缓存、不估算、无"过期快照"）。

行为：光标移动**只把标记换成箭头，不自动滚动**（位置完全由用户掌握）；点标记跳到另一侧，**窄屏下顺带切换到另一侧**（编辑/预览同屏的宽屏不切换，且此时点编辑区标记会保留焦点以便继续输入）。

| 关注点 | 位置 |
|---|---|
| 锚点模型与切分（含不变量 `raw` 拼起来 == 原文） | `lib/core/parser/bbcode_anchors.dart` |
| 预览逐锚点渲染 + 定位 API（`revealAnchor`） | `lib/widgets/editor/editor_preview.dart` |
| 标记槽（圆点/箭头/点击；编辑区与预览共用） | `lib/widgets/editor/block_marker_gutter.dart` |
| 编辑区行测量（问 `RenderEditable` 要真实光标矩形） | `lib/widgets/editor/editor_line_metrics.dart` |
| 两边同源、光标 → 锚点、点标记跨区跳转（含窄屏切换） | `lib/pages/editor/editor_page_locator.dart` |

**动手前必读**：`docs/07` #69（为什么禁止"算偏移/文字匹配"）、#70（Windows AXTree 刷屏的三层处理）。保真度探针：`tool/anchor_fidelity_probe_test.dart`。

## 快照系统

编辑器内容自动保存到本地数据库（sembast，`editor_snapshots` store），sessionKey 由 `EditorHistoryProvider.generateKey()`（`lib/providers/editor_history_provider.dart`）按 `EditorType` 生成，共五种形态：

| EditorType | key 形态 |
|---|---|
| post | `post_{ts}_{rand}` |
| comment | `comment_{tid}` |
| reply | `reply_{tid}_{pid}` |
| editPost | `editPost_{tid}_{pid}` |
| editReply | `editReply_{tid}_{pid}` |

不含 host、无固定前缀。formhash 过期后快照仍有意义（发帖场景）。

自动保存去重：`contentHash` 比较，去重窗口 2 秒。

提交后保留快照（不自动删除），用于 "再次编辑" 场景。

## 三种图片来源

1. 上传的（`_handleImageUpload` → 调用 `/misc.php?mod=swfupload`）
2. 未使用的（`upload_api.fetchUnusedImages`）
3. 已绑定的（编辑帖子时已有的附件）

`ImagePickerSheet` 统一管理，选中后插入 `[attachimg]aid[/attachimg]`。

## 表情

在 `EmojiService`（`lib/core/app/emoji_loader.dart`）初始化时将 `[s:{id}]` 及 Smilies 等预处理为 `{text}{emoji_{id}}{text}` 格式，便于后续 BBCode 解析。

## MT 图床

`MtImageHosting` 懒加载服务：首次上传时 GET `img.binmt.cc` → 从 HTML `<meta name="csrf-token">` 提取 token → 缓存 session 约 2 小时。
上传队列支持多文件，历史记录持久化到本地数据库（sembast）（最多 200 条，编辑器只显示最近 20 条未隐藏的）。

## 粘贴图片

Ctrl+V 拦截：通过 `ClipboardPasteService`（`lib/services/clipboard_paste.dart`）调 PowerShell 加载 `System.Windows.Forms`，按序用 `Clipboard.GetFileDropList`（原始文件路径）→ 原始编码字节（PNG/GIF/JFIF）→ `Clipboard.GetImage()` 兜底检测剪贴板图片 → 保存临时文件 → `upload_api.uploadImage()` 上传 → 插入 `[attachimg]`。无对话框，无文本回退。（未使用 `Get-Clipboard`。）
