# 编辑器

> 适用：编辑器开发（模式/数据流/预览与跨区定位/快照/图片/表情/图床/粘贴）。按需，写操作协议见 12。

## 五种模式

发帖 / 评论 / 回复评论 / 编辑帖子 / 编辑评论，通过 `EditorType` 枚举区分，URL 绑定见 `EditorSubmitHelper._buildUrl()`（`lib/pages/editor/editor_submit.dart`）。

## 数据流

```
PageFetcher 提取 formhash/hash/uid → 编辑器初始化
  → 用户编辑 → 提交 → API（只做纯提交，不做 fetch）
  → parseSubmitResponse() 统一解析 → SnackBar 结果
```

API 层重构后就地：旧架构 API 自己做 fetch，新架构 API 只提交，formhash 由编辑器统一传入。

## 共享内核（EditorSession）与迷你编辑器

完整版编辑器与迷你版**共用** `lib/pages/editor/editor_session.dart` 的 `EditorSession`：
内容/标题控制器、页面数据（formhash 等）、引用帖、快照 key、提交协议，以及
`switchTarget()`（帖子页"评论 ↔ 回复某评论"切换）。内核**不依赖 `BuildContext`**——
弹窗 / Toast / 主题留在各自的界面层（Surface）。

- **完整版** `EditorPage`：持有 `_session` + 全屏布局（预览 / 锚点 / 标记槽）。界面侧
  直接读写 `_session.xxx`（无转发层），存储的唯一来源是 `EditorSession`。
- **迷你版** `MiniEditorBar`（`widgets/editor/mini_editor_bar.dart`）：紧凑输入 +
  精简工具栏 + 收起/完整版按钮 + 目标芯片。
  - **帖子页**（`pages/thread/`）：作为底部栏内嵌，替代原来的"push 全屏"评论流。
    - 收起态 = 现有"说点什么"胶囊；展开态 = `MiniEditorBar`（不遮挡正文，可收起读帖）。
    - **目标切换**：点"说点什么"= 评论帖子（`EditorType.comment`）；点某条评论的"回复"
      = `switchTarget(EditorType.reply, pid)`，顶部显示"回复 @某人"芯片。
    - **点芯片弹预览**：弹窗用 `PostHtmlWidget` 渲染被回复的评论（`viewpid` 预取）。
    - **关闭回复 = 收起编辑器**：芯片**不提供"取消目标"按钮**，避免"还在回复评论？
      还是回复帖子？"的歧义；`_collapseEditor` 收起并把目标重置为 comment。
    - **提交成功自动收起**（同时重置目标，恢复浏览态）。
    - 提交复用 `_appendPost` / `_reloadMainPostIfLocked`（"回复可见"解锁），逻辑与
      `_openEditor` 一致；`_openEditor` 返回 `bool` 表示发布成功。
    - **图片分两项**：`image` = 论坛图片上传（`pages/editor/forum_image_upload.dart`
      的 `uploadForumImagesQuick`，选图→上传→插入 `[attachimg]`）；`mtImage` = MT 图床外链。
      附件上传/管理走「完整版」。
  - **私信页**（`pages/message/pm_chat_page.dart`）：替换原输入框；无标题/无附件、
    也无论坛图片上传，故 `image` 在私信上下文被过滤，只用 `mtImage`（MT 图床）；
    **保留**原有乐观发送 / 轮询 / 去重逻辑（见 docs/07 #85/#86）。
  - **顶部单行**：回复目标芯片 + 工具栏 + 右上角（预览 / 完整版 / 收起）**同一行**，
    避免出现"只有几个按钮的空行"；预览用 `PostHtmlWidget` 直接渲染正文（预览时收起
    工具栏但按钮仍在右侧）。底部仅保留「发送」。
  - **常用语**：作为**工具栏项 `quickReply`**（默认：完整版隐藏 / 帖子页迷你显示；
    私信页不支持）。点按 → **弹窗选择**后插入（弹窗右上角有设置入口，直进编辑器设置）。
    默认取自 `assets/config/quick_replies.json`（`items`；读取失败兜底
    "感谢分享 / 看看隐藏 / 论坛有你更精彩"）。
    - **显示 / 插入分离**：`name` = 显示文本（≤ `kQuickReplyMaxLength` = 100）；可选
      `data['insert']` = 实际插入内容（≤ `kQuickReplyInsertMaxLength` = 500，可含 BBCode），
      留空则插入显示文本。编辑弹窗两个字段（`widgets/dialog/quick_reply_dialog.dart`）。
    - 管理入口：设置 → 编辑器设置 → **帖子常用语**（增删改 / 排序 / 显隐，复用
      `showManagedListDialog`）。
  - **撤销 / 重做**：由**工具栏项** `undo`/`redo` 提供（与正文 TextField 共用同一个
    `UndoHistoryController`，经 `EditorActionHooks.undoController` 生效）；迷你版底部
    不再固定撤销/重做，只保留「发送」。工具栏禁用态只用图标透明度表达，**不加底色**。
  - **可关闭**：设置 → 编辑与快捷键 → **帖子页迷你编辑器**（默认开启）。关闭后帖子页评论/回复
    退回原全屏 `/editor`（`_navigateComment` / `_replyToPost` 分支判断）。
  - **返回 / Esc**：迷你编辑器展开时，**先收起编辑器**，再按才返回页面
    （帖子页 `_wrapBackToCollapse`：页面级 `Shortcuts` 覆盖 Esc + `PopScope(canPop:false)`
    拦 Android 返回）；未展开时交回全局 Esc / GoRouter 默认行为。
  - 迷你编辑器**不注册**工具栏键盘快捷键（页面级 `Shortcuts` 只服务完整版）。
- **共用动作分发**：`pages/editor/editor_interactions.dart` 的 `dispatchToolbarItem(...)`
  + `EditorActionHooks`。模板项、链接、表情、颜色、字号、清除格式等通用动作在内核实现；
  图片/附件/图床/历史/导入等上下文相关入口由各自 Surface 注入回调。
- **展开为完整版（草稿交接）**：调用方先写快照保底，再把草稿放入
  `pages/editor/editor_draft_handoff.dart` 的 `EditorDraftHandoff`（按 type+tid+pid 单槽匹配）；
  全屏 `/editor` 打开时取出并预填正文，随后清理本地草稿。

工具栏是**一套**（不是三套）：完整版与两个迷你版**共用同一份 `toolbarItems`（同一顺序）**，
差异只在**各上下文的可见性**。每项的默认可见性写在 `assets/config/toolbar.json`：
- `visible` —— 完整版默认是否显示
- `mini` —— 迷你编辑器默认可见的上下文 id 数组（如 `["thread","pm"]`；缺省 = 迷你版不显示）

持久化在 `data['mini']`（**始终保留该键**，空列表也要写，否则合并默认值时无法隐藏）。
设置入口：设置 → 编辑器设置 → 工具栏
- **完整编辑器工具栏**：排序 + 增删改（自定义模板）+ 完整版显隐（顺序在此统一管理）
- **迷你工具栏 · 帖子页 / 私信页**：展示**整条工具栏**（顺序即共享顺序，故**此处也能排序**），
  只切换该上下文的显隐；该上下文不支持的项禁用显隐开关（`canToggleVisibility`）
- 面板标题栏提供 **「只看已显示项」** 勾选（`allowFilterVisible`）：隐藏项多时减少干扰
  （迷你版只启用一小部分时尤其明显）。**排序仍可用**：内部用 `reorderVisibleToFull`
  把可见子序列的重排换算成对完整列表的一次移动（只保证可见项相对顺序；隐藏项可能位移）。

上下文不支持的项由 `kMiniToolbarUnsupported` 过滤（帖子页排除 `attach`；
私信页排除 `image`/`attach`/`quickReply`），避免"显示某图标点了却是别的功能"。

## 发布前本地预校验

点「发布」后、真正提交前，编辑器做两项**纯本地**校验（判定逻辑在 `editor_precheck.dart`，有单测）：

| 校验 | 触发条件 | 行为 |
|---|---|---|
| 不兼容 Emoji | 正文含码点 > U+FFFF 的字符（4 字节 UTF-8，站点会截断） | **阻止本次提交**，弹窗可一键删除。删除用 `_contentCtl.value = TextEditingValue(整篇替换)` 写回 → 进入 UndoHistory，用户可「撤销」反悔。判定与顶栏提示同源（`countIncompatibleEmoji`） |
| 未插入正文的媒体 | 已上传的图片/附件 aid 不在正文的 `[attachimg]`/`[attach]` 标记里（`uninsertedMedia`，判定与两个 picker 面板的「已插入」一致） | 弹窗告知"会被追加到正文末尾"，确认后这些 aid 随 `attachnew` 一并提交；取消则不发布 |

**关键**：图片与附件都**必须**进 `attachnew` 才会绑定到帖子（只发 `message` 的话，未引用的附件根本不会出现在帖子里）。编辑器把两类 aid 一起传给 `EditorSubmitHelper.submit(..., appendAids:)`。

## 工具栏（数据驱动 + 模板项）

工具栏项的唯一数据源是 `assets/config/toolbar.json` 的 `items` 段（JSON 读取失败时兜底
`config/toolbar_config.dart` 的 `allToolbarItemConfigs`）；`BBCodeToolbar` 渲染、编辑器快捷键、
设置页排序/显隐全部从此派生（docs/07 #9）。

工具栏项分两类：

| 类型 | 判定 | 行为 | 例 |
|---|---|---|---|
| **模板项** | `data.template` 非空 | 用文本模板包裹选中文字 | `[b]${selectText}[/b]` |
| **复杂项** | 有对应 `ToolbarAction` | 弹窗 / 面板 / 上传 | 图片、表情、链接、颜色、字号… |

模板项字段：`template`（含 `${selectText}` 占位符，见 `kSelectTextToken`）、`label`（按钮文字）、
`group`（分隔线分组：相邻两项分组不同才画线）、`block`（无占位符时按块级插入，用于 `[hr]`/表格骨架）。

应用逻辑统一在 `BBCodeController.applyTemplate`：

- 有选中 → 选中文本（trim 后）替换 `${selectText}`，整体替换选区，光标落在末尾
- 无选中 → `${selectText}` 置空，光标落在原占位符处（`[b]|[/b]`）
- `block` 且无占位符 → 走 `insertBlockTag`（必要时补换行）

**用户自定义**：设置 → 编辑器设置 → 工具栏排序可新增/编辑/删除。自定义模板以
`ManagedItem.data` 存进 `toolbar_items`，复用同一套排序/显隐/快捷键。约束：内置项不可删
（下次同步会还原）、复杂项不可编辑（由代码实现）、仅模板项可编辑。重置默认会保留自定义项。

**分发**：`BBCodeToolbarController.onAction(id)` 与 `EditorToolbarIntent(id)` 一律按 **item id**
派发（模板项不是枚举成员），编辑器 `_handleToolbarItem` 据 id 决定走模板还是复杂动作
（`_handleToolbarAction`）。回归测试：`test/toolbar_template_test.dart`。

**末尾固定按钮**：渲染时在所有可配置项之后**固定追加一个「设置」按钮**
（伪 id `kEditorSettingsId`，打开 `/settings/editor`），**不受工具栏设置影响**（不可排序/隐藏）；
因此即使所有项都被隐藏，工具栏仍会渲染。它不在 `allToolbarItemConfigs` / `toolbar.json` 中。

**新增的两个复杂项**：「编辑历史」（`editHistory`，打开快照历史页 `/editor/history`）与
「导入MD」（`mdImport`，Markdown → BBCode 底部面板）。它们与其它项一样可排序/隐藏。

**数量角标（图片 / 附件）**：「图片」「附件」支持上传，二者在图标右上角带**数量角标**
（`BBCodeToolbar.badges`：item id → 数量；编辑器传入 `image` = `_imageList.length`、
`attach` = `_attachmentList.length`）。规则：**有角标时该项无视用户的隐藏设置强制显示**——
上传过东西却看不到入口，用户既得不到提示、也进不去管理面板；**无角标时隐藏设置照常生效**。
角标只影响工具栏渲染，设置页的排序/显隐数据不变。回归测试 `test/toolbar_template_test.dart`。

**快捷键与显隐**：默认隐藏项快捷键仍生效，可在「设置 → 编辑与快捷键 → 隐藏项快捷键可用」
关闭（见 docs/05「显隐与快捷键解耦」）。工具栏渲染与快捷键注册共用
`toolbarItemShown()`（`config/toolbar_config.dart`）判定"实际可见"。

## 预览与跨区定位（锚点）

预览**逐锚点渲染**：`bbAnchors(source)` 把源码切成锚点（顶层块 ∪ 空行分段 ∪ 整行加粗标题），编辑区与预览区**共用同一份锚点表**，下标即对应关系；预览给每个锚点一个 `GlobalKey`，位置靠 `findRenderObject() → localToGlobal` **现场读**（不缓存、不估算、无"过期快照"）。

行为：光标移动**只把标记换成箭头，不自动滚动**（位置完全由用户掌握）；点标记跳到另一侧，**窄屏下顺带切换到另一侧**（编辑/预览同屏的宽屏不切换，且此时点编辑区标记会保留焦点以便继续输入）。

| 关注点 | 位置 |
|---|---|
| 锚点模型与切分（含不变量 `raw` 拼起来 == 原文） | `lib/core/parser/bbcode_anchors.dart` |
| 预览逐锚点渲染 + 定位 API（`revealAnchor`） | `lib/widgets/editor/editor_preview.dart` |
| 标记槽（圆点/箭头/点击；编辑区与预览共用） | `lib/widgets/editor/block_marker_gutter.dart` |
| 编辑区行测量（问 `RenderEditable` 要真实光标矩形） | `lib/widgets/editor/editor_line_metrics.dart` |
| 两边同源、光标 → 锚点、点标记跨区跳转（含窄屏切换） | `lib/pages/editor/editor_page_locator.dart` |

**动手前必读**：`docs/07` #69（为什么禁止"算偏移/文字匹配"）、#70（Windows AXTree 刷屏的三层处理）。保真度探针：`tool/anchor_fidelity_probe_test.dart`。

## 快照系统

编辑器内容自动保存到本地数据库（sembast，`editor_snapshots` store），sessionKey 由 `EditorHistoryProvider.generateKey()`（`lib/providers/editor_history_provider.dart`）按 `EditorType` 生成，共五种形态：

| EditorType | key 形态 |
|---|---|
| post | `post_{ts}_{rand}` |
| comment | `comment_{tid}` |
| reply | `reply_{tid}_{pid}` |
| editPost | `editPost_{tid}_{pid}` |
| editReply | `editReply_{tid}_{pid}` |

不含 host、无固定前缀。formhash 过期后快照仍有意义（发帖场景）。

自动保存去重：`contentHash` 比较，去重窗口 2 秒。

提交后保留快照（不自动删除），用于 "再次编辑" 场景。

## 三种图片来源

1. 上传的（`_handleImageUpload` → 调用 `/misc.php?mod=swfupload`）
2. 未使用的（`upload_api.fetchUnusedImages`）
3. 已绑定的（编辑帖子时已有的附件）

`ImagePickerSheet` 统一管理，选中后插入 `[attachimg]aid[/attachimg]`。

## 表情

在 `EmojiService`（`lib/core/app/emoji_loader.dart`）初始化时将 `[s:{id}]` 及 Smilies 等预处理为 `{text}{emoji_{id}}{text}` 格式，便于后续 BBCode 解析。

## MT 图床

`MtImageHosting` 懒加载服务：首次上传时 GET `img.binmt.cc` → 从 HTML `<meta name="csrf-token">` 提取 token → 缓存 session 约 2 小时。
上传队列支持多文件，历史记录持久化到本地数据库（sembast）（最多 200 条，编辑器只显示最近 20 条未隐藏的）。

## 粘贴图片

Ctrl+V 拦截：通过 `ClipboardPasteService`（`lib/services/clipboard_paste.dart`）调 PowerShell 加载 `System.Windows.Forms`，按序用 `Clipboard.GetFileDropList`（原始文件路径）→ 原始编码字节（PNG/GIF/JFIF）→ `Clipboard.GetImage()` 兜底检测剪贴板图片 → 保存临时文件 → `upload_api.uploadImage()` 上传 → 插入 `[attachimg]`。无对话框，无文本回退。（未使用 `Get-Clipboard`。）
