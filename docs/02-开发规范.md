# 开发规范

> 适用：新增/修改 API、文件、UI 时遵守的开发约定。**必读。**

## API 新增流程（8 步）

1. 分析目标页面 → 确定 URL 和参数
2. `lib/api/{name}/` 下创建三个文件
3. `http.dart` — 发送请求，只做 `dio.get/post`，**不允许**调 parse
4. `parse.dart` — 纯函数解析 HTML/XML → JSON，**不包含**网络逻辑
5. `tool/api_scenarios.dart` 注册探针场景，用 `flutter test tool/api_probe_test.dart --dart-define=cmd={name}` 真实请求验证（见 `docs/10-API探针使用规范.md`、`docs/11-新增功能开发流程.md`）
6. `export.dart` — 导出 `fetchXxx` 便捷方法
7. 挂载到 Flutter 服务层（`services/` 或页面层调 export）
8. 验证

## Import 规范

**统一使用 `package:mtbbs/...` 绝对路径导入**，禁止使用相对导入（`../`、`../../`）。

```dart
// ✅ 正确
import 'package:mtbbs/core/app/site_store.dart';
import 'package:mtbbs/core/utils/logger.dart';
import 'package:mtbbs/config/config.dart';
import 'package:mtbbs/widgets/bbcode/bbcode_toolbar.dart';
import 'package:mtbbs/widgets/common/user_avatar.dart';
import 'package:mtbbs/widgets/layout/app_shell.dart';
import 'package:mtbbs/widgets/dialog/rate_dialog.dart';

// ❌ 禁止
import '../../core/site_store.dart';
import '../../../widgets/user_avatar.dart';
import 'core/logger.dart';
```

例外：barrel 文件的 `export` 使用同目录相对路径。

```dart
// barrel 文件 (如 widgets/bbcode/bbcode.dart)
export 'bbcode_toolbar.dart';        // 同目录，✅
```

### barrel 文件速查

| barrel 文件 | 用途 |
|---|---|
| `config/config.dart` | 聚合 5 个配置 |
| `models/models.dart` | 聚合 8 个 model |
| `widgets/widgets.dart` | 顶层 → 6 个子 barrel（bbcode/thread/dialog/layout/common/image_preview） |
| `core/core_parsers.dart` | barrel → parser/ |
| `core/core_utils.dart` | barrel → utils/ |
| `core/core_app.dart` | barrel → app/ |

## 文件命名规范

- `lib/api/{name}/` — 三文件：`http.dart` / `parse.dart` / `export.dart`
- `tool/` — API 探针场景注册（`tool/api_scenarios.dart`）与执行（`tool/api_probe_test.dart`），真实请求验证
- `lib/services/` — `{domain}_service.dart`（如 `mt_image_hosting.dart`）
- `lib/pages/{feature}/` — 页面 + 子组件拆分，>500 行时拆分
- `lib/widgets/` — 功能独立的可复用组件

## 日志规范

- 全局：`AppLogger.{d/i/w/e}(tag, message)`，**禁止** `print` / `debugPrint`
- 标签约定：`DIO` / `PARSE` / `PAGE` / `CACHE`
- 开关：`AppLogger.enabled = false` 全局关闭

## 通用 UI 规范

- 对话框：`maxWidth: 360~420`，必须有关闭按钮，`barrierDismissible: true`
- 错误页：`PageErrorWidget` 统一使用，不弹 SnackBar，提供重试按钮
- 站点切换类界面不显示关闭按钮（用户必须选一个站点）
- 点赞/收藏等无参数操作：直接 GET，无对话框

## 图片加载规范

### 禁止项

- **禁止**使用 `Image.network()` — 无磁盘缓存、不支持自定义请求头
- **禁止**使用不指定 `cacheManager` 的 `CachedNetworkImage` — 框架默认缓存不带 Referer

### 强制要求

所有网络图片必须使用以下模式之一：

```dart
// 帖子图片、封面图、画廊、图床缩略图 → imageCacheManager
CachedNetworkImage(
  imageUrl: url,
  cacheManager: imageCacheManager,
)

// 用户头像 → avatarCacheManager
CachedNetworkImage(
  imageUrl: url,
  cacheManager: avatarCacheManager,
)

// 表情图片 → emojiCacheManager
CachedNetworkImage(
  imageUrl: url,
  cacheManager: emojiCacheManager,       // 或通过 StaggeredEmojiImage 组件
)
```

### 初始化

`main.dart` 中调用 `initCacheManagers(emojiDays, avatarDays, imageDays)` 初始化三个管理器。

> 完整规范见 `docs/01-概述与架构.md` →「图片缓存规范」和「Referer 模拟策略」。
