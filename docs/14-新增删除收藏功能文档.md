# 14-新增删除收藏功能文档（完整开发记录）

> 适用：写功能实战参考（需求→MCP→API→探针→UI→回归全流程）。按需。

> 以"删除收藏"为例，记录一个 API 功能从需求分析到双站点验证的完整新增过程。
> 覆盖：MCP 分析 → API 层 → 探针场景 → UI → 回归验证 → 踩坑修复。
> 通用方法论见 docs/11-新增功能开发流程.md。

## 1. 需求

收藏页只有数据展示，没有删除功能。需要：删除指定收藏，UI 带二次确认 + toast。

## 2. MCP 分析（DOM 证据）

Chrome 打开收藏页（`home.php?mod=space&do=favorite&view=me`）：

```html
<li id="fav_9">
  <a class="y" id="a_delete_9" href="home.php?mod=spacecp&ac=favorite&op=delete&favid=9"
     onclick="showWindow(this.id, this.href, 'get', 0);">删除</a>
  <input type="checkbox" name="favorite[]" value="9">
</li>
```

- **删除入口**：`home.php?mod=spacecp&ac=favorite&op=delete&favid={favid}`（favid = `input[name="favorite[]"]` 的 value）
- **确认表单**（导航到该 URL 后）：`#favoriteform_{id}` → POST action `...op=delete&favid={id}&type=all`，隐藏字段 `referer`/`deletesubmit=true`/`formhash`

## 3. API 层设计

| 文件 | 内容 | 要点 |
|---|---|---|
| `lib/api/home/favorite/http.dart` | `deleteFavorite(dio, favid, formhash)` | POST；`Content-Type` 显式；**`followRedirects:false` + `validateStatus:<500`**（Discuz 成功返回 301） |
| `lib/api/home/favorite/export.dart` | `deleteFavorite(dio, favid)` | **联动**：先 GET 列表页提取全局 formhash（CSRF），再调 http 删除。调用方只需 favid |
| `lib/api/home/favorite/parse.dart` | `parseDeleteResult` | 301/302→成功；错误关键词→失败文案 |

**联动设计**：formhash 是会话级 CSRF 令牌，藏在列表页隐藏 input 里（非删除接口直接给出），所以删除必须"先拉列表页拿 formhash 再删"。这是写操作 API 的通用模式（post 系列同理拿 formhash+posttime）。

## 4. 探针场景

- `favorite.list`（read_scenarios.dart，需登录）：返回 favid/tid/标题
- `favorite.delete`（write_scenarios.dart，需登录）：`favid` 必填 → `favorite_api.deleteFavorite`

**同时**：`api_probe_test.dart` args 白名单补 `favid` 键（逐键 const 读取，新参数键必须手动注册，否则静默丢参）。

## 5. UI 实现（favorite_page.dart）

- `_FavoriteCard` 加删除按钮（`Icons.bookmark_remove_outlined`）+ `onDelete`/`deleting` 参数
- State 加 `_confirmDelete`：AlertDialog 二次确认 → 调 API → 成功移除条目 + SnackBar「已取消收藏」；失败 SnackBar 错误；删除中按钮转圈禁用

## 6. 回归验证（实测结果）

| 步骤 | 命令/操作 | 结果 |
|---|---|---|
| 列表 | `favorite.list account=user1 baseUrl=http://discuz.qcxs.top` | 5 条 ✓ |
| 删除 | `favorite.delete favid=9` | 成功（301 跳转=已删） |
| Chrome | 刷新收藏页 | 5→4 ✓ |
| 再删 | `favorite.delete favid=4` | `取消收藏成功` |
| Chrome | 刷新 | 4→3 ✓ |
| 跨站点 | MT 论坛 `favorite.delete favid=673781 account=青春向上` | `取消收藏成功`，Chrome 确认消失 ✓ |

## 7. 踩坑与修复（按时间序）

1. **title/tid 解析为空**：parse 只认伪静态 `thread-4-1-1.html`，测试站是动态 `viewthread&tid=4` → 正则兼容两种格式
2. **`favid` 键缺失**：探针报"缺少必填参数: favid" → args 白名单补键
3. **Dio 把 301 当错误抛**：首次删除实际成功但报 DioException → 加 `followRedirects:false` + `validateStatus:<500`，parse 层判 Location。**教训：Discuz 写操作成功可能返回 301 跳转，Dio 默认不放行**
4. **偶发 `HandshakeException`**：MT 论坛首次握手失败，重试成功（网络抖动，非代码问题）
