# 通用组件与复用清单

> 适用：新增页面/弹层/列表/API 前，先查这里有没有现成件；避免各页各写一份。**必读**（配合 `docs/02-开发规范.md` 的 UI 约定）。

## 一句话

**能复用就不要新写**：布局骨架、状态视图、弹层容器、分页条、解析样板分别有唯一权威实现，本文按「你要做什么 → 用哪个」组织。

## 底部面板 / 弹层

| 需求 | 用 | 位置 |
|---|---|---|
| 打开底部面板（统一圆角/宽度/安全区） | `showAppSheet(context:, builder:, maxHeight: 560)` | `widgets/common/app_sheet.dart` |
| 面板骨架（拖拽手柄 + 标题 + 操作按钮 + 关闭 + 分隔线） | `AppSheetScaffold(title:, actions:, child:)` | 同上 |
| 只要拖拽手柄（自定义头部） | `SheetDragHandle(bottom:)` | 同上 |
| 插入 MT 图床外链 | `showMtImageSheet(context, hosting:, onInsert:)` | `pages/editor/mt_image_sheet.dart` |
| 统一确认框（返回 `true/false`） | `showConfirmDialog(context, title:, message:, danger:)` | `widgets/dialog/confirm_dialog.dart` |
| 可增删排序的列表管理面板（首页区块、表情、图床等） | `showManagedListDialog(...)` | `widgets/dialog/managed_list_dialog.dart` |

要点：

- `showAppSheet` 已固定 `maxWidth: appSheetMaxWidth(560)`、顶部圆角、`useSafeArea`；**不要再手写** `showModalBottomSheet + shape + constraints`。
- 面板内容含不定长列表/长文本时，用 `AppSheetScaffold` 的 `child` 放 `Expanded + ListView` 或 `SingleChildScrollView`（约束见 `docs/02` 弹层规则）。
- 自带 Material 手柄的 `showDragHandle: true` 面板（私信长按菜单、缓存面板）语义不同，不必强行统一。

## 列表 / 分页 / 状态

| 需求 | 用 | 位置 |
|---|---|---|
| 全页加载中 | `LoadingView()` | `widgets/layout/state_views.dart` |
| 空状态（可换图标/文案） | `EmptyView(icon:, text:)` | 同上 |
| 加载失败 + 重试/返回 | `PageErrorWidget(message:, onRetry:, showBack:, extraActions:)` | `widgets/layout/page_error_widget.dart` |
| 触底加载底部状态 | `LoadMoreFooter(loading:, hasMore:, endText:)` | `widgets/layout/load_more_footer.dart` |
| 页面底部固定分页条 | `BottomPaginationBar(page:, totalPages:, onGoToPage:)` | `widgets/layout/pagination_bar.dart` |
| 只要按钮行（嵌入头部/自定义容器） | `PaginationBar(page:, totalPages:, onGoToPage:)` | 同上 |
| 消息类列表 Tab（下拉刷新/触底加载/加载-错误-空态） | `PagedListStateMixin`（实现 `fetchPage`，按需覆写钩子） | `pages/message/paged_list_state.dart` |
| 提醒/我的帖子：子类型 chip + 二级左右滑动 + 未读校正 | `NoticeSubtypeStateMixin`（`buildNoticeTab`） | `pages/message/notice_subtype_state.dart` |
| 提醒/我的帖子：结构化段落（用户/主题链接/留言引用） | `buildNoticeSegments(context, segments, includeQuote:)` | `pages/message/notice_segments.dart` |

要点：

- `BottomPaginationBar` 已含 `SafeArea + 统一内边距`，页面里只写一行，不要再套 `SafeArea + Padding`。
- 长列表优先「触底加载 + `LoadMoreFooter`」，不要为了翻页而翻页（参考 `pages/favorite/favorite_page.dart`）。
- 消息 Tab 三件套是**模块内复用**（`lib/pages/message/`）：新增消息类 Tab 直接 `with PagedListStateMixin` 实现 `fetchPage`；需要子类型分组再叠加 `NoticeSubtypeStateMixin`，重写 `noticeView` / `configuredTypes`。
- 刷新已有内容失败时要保留旧列表（只有空列表才切整页错误态）；`PagedListStateMixin` 的整页加载语义适用于「首屏即列表」的 Tab。

## 页面通用块

| 需求 | 用 | 位置 |
|---|---|---|
| 内容页顶部「刷新 + 浏览器打开/复制链接」 | `PageActions(url:, onRefresh:, loading:, copyLabel:, extraItems:, onExtraSelected:)` | `widgets/common/page_actions.dart` |
| 用户列表页顶部账号卡片 | `AccountHeader(profile:, uid:, fallbackLabel:)` | `widgets/common/account_header.dart` |
| 本地过滤搜索框（用户名/UID） | `FilterSearchField(controller:, query:, onChanged:, hint:, padding:)` | `widgets/common/filter_search_field.dart` |
| 头像（CDN/缓存/错峰/点击进主页） | `UserAvatar(uid:, radius:, nickname:, tapAction:, onTap:)` | `widgets/common/user_avatar.dart` |
| Toast（不依赖页面 context） | `showToast(message, duration:)` | `widgets/common/toast_utils.dart` |

要点：

- 内容页顶部**不要**写裸 `IconButton(Icons.refresh)`；统一走 `PageActions`（见 `docs/02`）。
- 头像必须走 `UserAvatar` / `CachedNetworkImage` + 指定 `cacheManager`，禁止 `Image.network`（见 `docs/01` 图片缓存规范）。
- 错误提示用 `PageErrorWidget`，不要用 SnackBar/Toast 代替整页错误态。

## 数据层（`lib/api/`）

| 需求 | 用 | 位置 |
|---|---|---|
| 整页 HTML 前置校验 + 错误页/登录页/拦截页识别 | `prepareDoc(body, statusCode)` | `lib/api/helpers.dart` |
| export 层统一解析 + 日志 | `parseWithLog(resp, parseFn)` | 同上 |
| 分页字段（`currentPage/totalPages/hasMore`） | `...pagedFields(doc)` | 同上 |
| API 结果错误文案（成功返回 `null`） | `apiErrorText(result)` | 同上 |
| 帖子列表页解析（版块/导读共用） | `parseThreadListPage(body, statusCode)` | 同上 |

要点：

- 新增 API 仍须三文件（http / parse / export），parse 只做纯解析，日志交给 `parseWithLog`；详见 `docs/02`、`docs/10`。
- 分页字段统一用 `pagedFields(doc)` 展开，**不要**再写 `cp = pagination['currentPage'] ?? 1` 那套样板。

## 维护规则

- 新通用件优先放 `widgets/common/`（跨模块）或 `widgets/layout/`（布局/状态）；两个以上页面重复同一段 UI 就该抽取。
- 抽取前先搜本文与 `lib/widgets/`，确认没有同类实现；抽取后同步更新本文与 `docs/02` 的对应约定。
- 组件只提供「结构与样式」，业务数据/请求留在页面或 Provider；不要在通用件里发请求。
- 单文件超过 500 行按 `docs/02` 拆分（`part + extension` 或独立 widget），不要把通用件堆进页面文件。
