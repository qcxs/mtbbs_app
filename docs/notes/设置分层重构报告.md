# 设置分层与存储重构报告（归档要点）

> 状态：**已实施**（破坏性重构，不读取旧扁平键）。本文是设计决策的压缩存档，完整过程见 git 历史；当前实现与用法以 `docs/04-状态管理.md` 和 `lib/core/settings/settings_repository.dart` 为准。
> 适用：想了解「设置为什么按作用域分层」「为什么读取按 host、而不是切站时 push」时读。临时笔记，不进正式索引。

## 重构前的问题（已随实现消失）

- 所有设置混在 `app_settings` 一张扁平 KV 里，`getMeta/setMeta` 的缓存数据也塞在同一 Store。
- 「按站点隔离」有 5 种写法：独立 Store（`credit_formula`）、`{key}_{host}` 后缀、塞进 `Site` 对象、聚合 Map（`site_cdn_map`）、内存 Map 写入时拼 host；还有若干语义是站点、存储却是全局单键（Referer、人机验证、页面接管、字数限制）。
- 读取方拿不到「这是哪个站点/账号的设置」这一上下文，只能在启动/切站时手工 push 到模块变量，漏一步就出错。
- 默认值分散在 `assets/config/*.json`、Provider 初始值、`DefaultConfig` 兜底、setter `clamp` 四处，文档默认值常与代码漂移。

## 最终模型（已落地）

| Store | Key | 内容 |
|---|---|---|
| `settings_app` | `app` | `AppSettings`：外观、启动、阅读、编辑器、缓存、分享、历史等应用设置 |
| `settings_site` | host | `SiteSettings`：Referer/人机验证、页面接管、字数、空间数据源、积分公式、快捷链接、默认用户、CDN |
| `settings_account` | `host\|uid` | `AccountSettings`（预留账号级偏好） |
| `site_state` | `host\|kind` | 站点派生状态：表情缓存、作者资料等，**不属于用户设置** |

- 所有读取走 `SettingsRepository.instance.app` / `.site(host)`，是**启动时加载好的同步内存快照**；API 拦截器、路由 redirect、图片缓存都按目标 host 直接查，不再依赖切站回调。
- 写入统一走对应作用域模型；禁止新增 `setSetting('xxx')` 扁平键。
- 文档不存在或解析失败时按域回退默认值，不影响其它域。

## 关键决策

1. **不做旧键迁移**：重构按破坏性变更落地，旧扁平键不读取；换了新文档后回到默认值。
2. **派生数据与用户设置分开**：CDN、表情、作者资料属于站点状态，放 `site_state`，不污染 `SiteSettings`。
3. **切站不再重载 per-site 配置**：读取按 host 实时取快照，`SiteConfig.switchTo` 只负责当前站点指针与 Provider 数据。
4. **设置入口按作用域拆**：应用设置 / 站点设置 / 账号设置，站点设置页顶部固定站点选择器。
5. **账号级设置只留入口**：`AccountSettings` 当前仅预留，避免过早设计。
