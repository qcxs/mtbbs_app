# 依赖更新调研报告

> 适用：计划升级 `pubspec.yaml` 前阅读，判断每个依赖的更新性质、对本项目的影响与风险。环境快照：Flutter 3.44.2 / Dart 3.12.2（2026-11-06）。`latest` 不代表可安装，以 `flutter pub outdated` 的 `resolvable` 为准。

## 结论速览

| 决定 | 包 |
|---|---|
| A. 可直接升级（预期无代码改动） | dio、dio_cookie_manager、crypto、html、url_launcher、mcp_dart、sembast、flutter_cache_manager |
| B. 可升级但要改代码 / 专项回归 | qr、cached_network_image、xml、go_router、file_picker |
| C. 零影响 | cupertino_icons（`lib/` 未引用，可升可删） |
| D. 当前 SDK 升不了，等 Flutter 3.47 / Dart 3.13 | flex_seed_scheme 5、window_manager 0.6、xml 7.1、cached_network_image 4.0.4+、qr 4.0.1 |
| E. 不单独决策 | 其余传递依赖（见末节） |

## A. 低风险，建议升级

- **dio 5.10.0 → 5.11.1**：新增 HTTP QUERY 方法；修复自定义 `responseDecoder` 下空响应体抛 `FormatException`；修复并发请求共享失败 Future 导致的挂起/未捕获错误。项目自定义了拦截器与重试链，收益直接，无破坏性变更。
- **dio_cookie_manager 3.4.0 → 3.5.0**：复用 `RequestOptions` 时避免重复 Cookie，同时保留调用方自带的 Cookie。多站点 / 多账号 Cookie 隔离场景值得升。
- **crypto 3.0.7 → 3.0.8**：补丁级。本机镜像已可见 3.0.8，pub.dev 主 changelog 页面尚未刷新；未发现破坏性变更。
- **html 0.15.6 → 0.15.7**：修复多余方括号导致 CDATA 无法闭合、script/style 文本转义、深层嵌套格式化元素的 O(N²) 防护，新增 `textContent`。论坛 HTML 解析收益明确，风险低。
- **url_launcher 6.3.2 → 6.3.3**：修复 `supportsCloseForLaunchMode` 返回值；最低 Flutter 3.41。项目只做常规外链打开，基本无感。
- **mcp_dart 2.4.2 → 2.4.3**：仅文档、agent skills 与示例修正，changelog 明确「公开 API、协议行为、最低 Dart 3.4 均不变」。当前是精确锁定版本，升级只需改一行，并同步 `docs/09-依赖清单.md`。
- **sembast 3.8.9+1 → 3.10.0**：新增导入导出选项（`SembastExportOptions` / `SembastImportOptions`，兼容 `$` 与旧 `@` 类型前缀）；事务内导出会包含未提交变更；修复内存库重开后非 ASCII 记录丢失。注意 3.9.0 起 `RecordsRef.put/add/update` 对非法值（裸 `DateTime`、非 merge 的 `FieldValue.delete`）由静默接受改为抛 `ArgumentError`。`DatabaseHelper` 统一 JSON 编码，预计无影响，但仍需跑数据层回归。
- **flutter_cache_manager 3.4.1 → 3.5.0**：缩放判定改为按文件内容（覆盖 webp/bmp 与通用 `Content-Type`），gif/apng/动画 webp 原样保留，缩放结果统一存 `.png`；3.4.4 起 `putFile` 等待元数据落库、失败即抛；3.4.7 清理遇删不掉的文件会继续。项目只用 `memCacheWidth/Height`（内存解码），不触发磁盘缩放；缓存清理按 repo 的 `relativePath` 删除，不依赖扩展名。兼容，建议升。

## B. 可升级，但需要改代码或专项回归

- **qr 3.0.2 → 4.0.0**（当前最高可解析 4.0.0）：`QrErrorCorrectLevel` 由整数常量类改为枚举（`low/medium/quartile/high`）；移除 `QrCode.fromData`，改为 `QrCode(QrPayload.fromString(data), errorCorrectLevel: ...)`；`QrImage` 保留；生成约快 50%。唯一改动点是 `lib/widgets/share/share_qr_code.dart`，改动小、收益明确。
- **cupertino_icons 1.0.9 → 2.0.0**：迁移到 `cupertino_ui`，最低 Flutter 3.44/Dart 3.12（正好满足）。`lib/` 未直接 import，属模板残留依赖，升级零影响；不想要也可直接删除。
- **cached_network_image 3.4.1 → 4.0.3**（4.0.4+ 依赖较新的 `material_ui`，当前不可解析）：4.0 起改用 `material_ui`（Wasm 兼容），最低 Flutter 3.44/Dart 3.12。项目只用 widget + `cacheManager`，不实现 `ImageLoader`，API 层兼容。建议与 `flutter_cache_manager` 3.5.0 同批升级，回归四层图片缓存。
- **xml 6.6.1 → 7.0.1**（7.1.0 需 Dart 3.13）：命名空间改为解析期固化；`namespace` 参数被 `namespaceUri/namespacePrefix` 取代；`XmlName` 不可变。项目仅在 `lib/api/forum/rss/parse.dart` 使用 `XmlDocument.parse + findAllElements + getElement('dc:creator')`，需用带 `xmlns:dc` 的真实 RSS 跑探针确认前缀匹配仍成立。风险中低，可等到 Flutter 3.47 直接上 7.1。
- **go_router 14.8.1 → 18.1.3**：破坏点集中在 15.0 URL 默认大小写敏感、16.0 `GoRouteData` 破坏（项目未用 codegen）、17.0 ShellRoute 导航默认通知 root observer（新增 `notifyRootObserver`）、18.0 迁移 `material_ui` 且最低 Flutter 3.44/Dart 3.12。收益：17.x 修复链式顶层 redirect、ShellRoute `onExit`、redirect 内无关异步错误被误包成 `GoException`、嵌套 shell 的 key 冲突。项目正好有双层 `ShellRoute` + 顶层 redirect（`lib/config/router.dart`、`lib/core/app/app_page_gate.dart`），收益与风险都集中在这里。升级必须专项回归深链、返回、shell 切换、页面接管；如需保持旧行为可显式 `caseSensitive: false`。
- **file_picker 8.3.7 → 13.3.2**：12.0 移除 `FilePickerResult`（`pickFiles` 返回 `List<PlatformFile>`，空列表代替 null）；`allowMultiple` 默认改为 true（单选改用新增的 `pickFile`）；`saveFile` 的 `fileName` / `bytes` 全平台必填；13.0 移除 12.0 起弃用的参数；`PlatformFile.length()` 返回 `Future<int?>`。项目调用集中在 `lib/platform/optional/file_pick.dart`（6 个 pick 调用点）与 `image_save.dart` / `file_save.dart`（5 个 save 调用点）；桌面端「不传 bytes、自己写盘」的模式必须改。鸿蒙分支的 `saveFile` 依赖 OH 侧插件把 `initialDirectory` 当源文件的语义，需和 mtbbs_app_ohos 同步验证。收益是 Android 选择可能永不完成、保存失败 `onFileSaving` 等修复。

## C. 当前 SDK 升不了（等 Flutter 3.47 / Dart 3.13）

- **flex_seed_scheme 4.0.1 → 5.0.1**：5.0 要求 Flutter ≥3.47，并切换到解耦的 material/cupertino UI。当前不可解析；等 Flutter 升级后单项做，回归主题色/夜间模式。
- **window_manager 0.5.2 → 0.6.0**：0.6 改为基于 nativeapi 的 C++ 核心，要求 Flutter 3.47/Dart 3.13；API 迁到 `legacy.dart` 兼容层，桌面 runner 侧代码要同步调整。当前不可解析；升级后回归 Windows 启动、窗口尺寸、标题栏、关闭拦截。
- **xml 7.1.0**：需 Dart 3.13，先停在 7.0.1。
- **cached_network_image 4.0.4+ / qr 4.0.1**：受 `material_ui` 与 SDK 约束，当前解析不到。

## D. 传递依赖：不单独决策

- **Flutter SDK 锁定，不建议手动 override**：intl、vector_math、meta、matcher、test_api、vm_service、clock、material_color_utilities、stack_trace、web、yaml、package_config。
- **随主包升级自动走**：archive、octo_image、mime、petitparser、sqflite 系列、synchronized、dio_web_adapter、url_launcher 平台实现、cached_network_image_web/platform_interface、cross_file。
- **仅 window_manager 0.6 时才有意义**：win32 5→6、screen_retriever 0.2→0.3、platform/posix。
- **Android/iOS 插件链，Windows 打包无关**：jni、jni_flutter、objective_c、code_assets、hooks、record_use。
- **不要用 `flutter pub upgrade --major-versions` 一把梭**：会同时改写 file_picker、go_router、cached_network_image 的大版本约束。

## 推荐执行顺序

1. 低风险批：`flutter pub upgrade`（A 组），手动把 `mcp_dart` 改为 `2.4.3`；跑全量验证。
2. 小改动批：`qr` ^4.0.0（改 `share_qr_code.dart`）+ `cupertino_icons` ^2.0.0（或删除）。
3. 图片栈批：`cached_network_image` ^4.0.3（与 `flutter_cache_manager` 3.5.0 同批）。
4. 路由批：`go_router` ^18.1.3，专项回归后再继续。
5. 文件选择批：`file_picker` ^13.3.2，与鸿蒙仓库同步验证。
6. 可选：`xml` ^7.0.1，用 RSS 探针验证命名空间。
7. 等 Flutter 3.47：`flex_seed_scheme` 5、`window_manager` 0.6、`xml` 7.1。

每批单独提交，便于回滚；不要在一个提交里混入多个大版本。
