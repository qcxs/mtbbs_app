# 圈子（Discuz 群组）

> 适用：涉及 `group.php` / 圈子页面、圈子只读浏览、或排查圈子相关解析时读。按需。

## 一句话

圈子 = Discuz **群组模块 `group.php`**，MT 已基本废弃，App 只做**只读**浏览。入口在「我的」页 → 圈子。

## 关键结论：必须用桌面模板

MT 对 `group.php` 有两套模板，**只有桌面模板能静态解析**：

| UA | 标题 | 结构 | 能否解析 |
|---|---|---|---|
| 桌面（`comiis_wide`） | 「群组」 | 服务端直出 HTML | ✅ 本项目采用 |
| 移动（克米） | 「圈子」 | 圈子列表由 **JS 动态加载**，静态 HTML 里 0 个 `group-*` 链接 | ❌ 无法解析 |

因此 [http.dart](../lib/api/group/groupindex/http.dart) **刻意不覆写 UA**，走 `ApiService` 默认的桌面 UA（与 viewthread 一致）。**不要把这里改成站点 UA**——移动模板会拿不到任何圈子数据。

## 三层结构与复用关系

| 层 | URL / 路由 | 实现 |
|---|---|---|
| 圈子列表 | `group.php?hot=yes`（首页）、`group.php?gid={gid}&page={page}`（分类） | **新增** [api/group/groupindex/](../lib/api/group/groupindex/) |
| 圈子内容（讨论区） | `forum.php?mod=forumdisplay&fid={gid}` → `/groups/content?gid={gid}` | **复用** `forum.list` + `CommunityPage(fid, title, readOnly)` |
| 圈子帖子详情 | `/thread/{tid}` | **复用** `thread.detail`，帖子渲染零改动 |

**要点**：圈子的 fid **就等于 gid**（圈子 57 → `forumdisplay&fid=57`），所以「讨论区」完全复用版块帖子列表链路（移动 UA 下命中 `ComiisCardParser`）。圈子内容页只是把标题换成圈子名、隐藏发帖入口。

## 权限

- 圈子**列表**（`group.php`）：游客可访问
- 圈子**内容 / 帖子详情**：游客被拒（"您没有权限访问该群组"），**登录后正常**；`checkPageError` 已将拒绝态识别为 `success:false`，页面按错误态展示

## 路由与映射

| App 路由 | 说明 |
|---|---|
| `/groups` | 圈子首页（推荐 + 分类 + 排行） |
| `/groups/category?gid=&name=&page=` | 分类下的圈子列表 |
| `/groups/content?gid=&name=` | 圈子内容（只读讨论区） |

[url_router.dart](../lib/core/utils/url_router.dart) 映射：`group.php?gid=N` → `/groups/category?gid=N`；`group.php` → `/groups`；`group-{gid}-{page}.html` → `/groups/content?gid={gid}`（回归见 `test/url_router_test.dart`）。

## 已知限制

- MT 圈子基本废弃：部分分类下为空（如「游戏」count=0），UI 用 `EmptyView` 兜底
- 圈子图标多为 CDN 地址，走 `imageCacheManager`；`static/image/common/groupicon.gif` 已在数据层补全为绝对地址（`normalizeUrl`）
- 未纳入「页面接管」开关（仅只读浏览，暂不需要）
