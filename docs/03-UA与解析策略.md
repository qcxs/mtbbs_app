# UA 设置 & 帖子列表解析

> 适用：处理 UA（移动/桌面）、帖子列表解析策略（ThreadListParserFactory）。按需。

## UA 控制

- **设置入口**：设置 → 站点 → 浏览模式（移动版/桌面版）
- **默认值**：桌面 UA（`Site.uaPc`）
- **存储位置**：`Site.userAgent`，持久化到 `Site.toJson`
- **生效范围**：仅在导读/板块/我的帖子/帖子提醒四个 HTTP 调用中使用可配置 UA
- **其他所有 API** 强制使用桌面 UA（`Site.uaPc`），避免 DOM 解析与移动版 HTML 结构不匹配
- **`ApiService` 默认请求头** 固定为 `Site.uaPc`，所有未显式覆写的请求走此默认值

```
可配置 UA 的 API（4 个）：
  forumdisplay   → site.userAgent → 板块帖子列表
  guide          → site.userAgent → 导读
  mythread       → site.userAgent → 我的帖子
  mypost         → site.userAgent → 帖子提醒

强制 PC UA 的 API（其余所有）：
  viewthread, viewpid, space, editor, ranklist, online, favorite,
  misc, 以及 ApiService 全局默认请求头 → Site.uaPc
```

- `mobile=2` 查询参数已全部移除，无需在 URL 中显式声明
- 52pojie 对 UA 不敏感，始终返回 PC 表格
- MT 论坛对 UA 敏感：移动→克米卡片，PC→标准表格或克米混合

## 解析策略模式

入口 `parseThreadList(html)` → `ThreadListParserFactory.parse(html)`

工厂自动检测顺序：

| 优先级 | 解析器 | 特征 | 场景 |
|--------|--------|------|------|
| 1 | ComiisCardParser | `li.forumlist_li.comiis_znalist` | MT 移动 |
| 2 | DiscuzTableParser | `#threadlist th.common` | 52pj + MT PC 导读 |
| 3 | ComiisTableParser | `div.comiis_postlist` | MT PC 板块 |
| 4 | SpaceThreadParser | `table tr.th td.icn` | 我的帖子（MT/52pj） |

所有解析器输出统一的 `ThreadItem`，渲染层 `ThreadCard` 只认此模型。
