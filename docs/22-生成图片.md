# 生成图片（分享图）

> 适用：新增/修改「生成图片」时必读——**新页面接入、改分享卡内容、动截图/拼接/保存、二维码、勾选项**。本篇只说方向与取舍，实现细节读代码；踩坑明细见 `docs/07 #91`。

## 一句话

分享图 = 把一段**真实组件树**渲染成 PNG（`RenderRepaintBoundary` → 按高度分块 `toImage` → CPU 拼接 → PNG）。所以"图长什么样"完全取决于**你交给它哪棵子树**——不要用画布/拼图另画一份。

## 现有实现

| 入口 | 图片内容 | 预览形态 | 生成页配置 |
|---|---|---|---|
| 楼层/评论（楼层卡片菜单） | 另写的一张分享卡：作者 + 正文 + 评分/打赏 + 页脚水印 | 新路由（`ShareImagePage` 骨架） | 3 个临时勾选项（评分 / 截断 / 二维码） |
| 个人主页（页面右上角菜单） | **页面自己的区块原样** | **页内预览**（`_sharing` 开关，不开新路由） | 无 |

## 两条路子（扩展前先选一条）

| | A. 独立卡片 | B. 页面区块直出 |
|---|---|---|
| 内容来源 | 为新卡片写渲染代码 | 复用页面构建区块的方法（页面抽一个 `_contentSections()`，正文列表与图片共用同一份） |
| 主题 | 可强制浅色，分享观感统一 | 跟随页面 |
| 与页面一致性 | 不必一致 | **完全一致**（就是同一棵子树） |
| 适合 | 要"精炼/好看/加料"的分享卡 | 用户要求"和页面一样" |
| 代价 | 页面改版需同步维护卡片 | 见下方硬约束 |

**选 B 的硬约束**：区块里若调用 `context.select`（本项目用户主页的头部/瓦片就是这么写的），**只能在 build 期间调用**——所以不能"在事件回调里拼好再塞给一个新路由"。这就是 B 采用**页内预览**（页面 `build` 里按 `_sharing` 切换 body）而非新路由的原因。

## 复用这些件（别重写）

| 件 | 位置 | 说明 |
|---|---|---|
| `CaptureBoundary` | `services/image_export.dart` | `RenderRepaintBoundary` 子类，暴露 `offsetLayer`（`layer` 是 `@protected`、`debugLayer` 在 release 恒为 null，都不能直接用） |
| `ImageExport.capturePng` / `ImageExport.save` | 同上 | 分块渲染 + CPU 拼 PNG；Android/iOS 走 `gal` 存相册，桌面 `FilePicker.saveFile` 另存为 |
| `ShareImagePage` / `ShareToggle` | `pages/share/share_image_page.dart` | A 的预览页骨架：浅色、截图、勾选项、保存、Esc |
| `ShareQrCode` | `widgets/share/share_qr_code.dart` | `qr` 编码 + 自绘方块，尺寸随便给（无"单模块 ≥ 2px"下限） |
| `ThreadSharePage` / `UserSharePreview` | `pages/thread/`、`pages/user/` | 两个已落地调用方，抄它们最快 |

## 接一个新页面（步骤）

1. 选 A 还是 B。
2. 备内容：A 写 `cardBuilder`；B 从页面抽出区块列表（**在页面 build 里构建**后再传给预览组件）。
3. 包进 `CaptureBoundary`，A 交给 `ShareImagePage.open`，B 交给一个页内预览组件（参考 `UserSharePreview`）。
4. 页脚加水印：站点（`MTBBS · {host}`）、定位信息（`tid/pid/uid` 用文字写清）、`ShareQrCode`。
5. 入口挂到页面右上角菜单（`PageActions.extraItems`）。
6. 跑 `flutter analyze lib` + `flutter test`。

文件名统一 `{前缀}_{时间戳}`，前缀用业务 ID（`MTBBS_{pid}` / `MTBBS_user_{uid}`）。

## 已定的取舍（别推翻）

- **不做外部分享**（`share_plus` 桌面端文件分享不可靠），只"存相册 / 另存为"。
- **勾选项是临时的**：只存在于生成页、默认全开、不持久化；设置里只留"需要长期存在"的项（截断高度、只生成内容图）。
- **内容永远来自真实组件树**，不做画布另画。

## 坑索引（症状 → 去向）

| 症状 | 一句话根因 | 详见 |
|---|---|---|
| 超长内容很糊 | 一次 `toImage` 撞 GPU 单张纹理上限 → 被迫降采样 | `docs/07 #91` |
| `Failed assertion: 'min <= max'` | `pretty_qr_code` 断言单模块 ≥ 2px | 同上 |
| 宽屏生成后返回列表页，图片重新加载 | 解码宽度随布局变 → 同一张图多份解码，挤爆 `imageCache` | `docs/07 #91`（有完整推导） |
| 预览页 Esc 关不掉 | 新路由不在 `GlobalShortcutsWrapper` 覆盖范围内 | 同上 |
| 截到占位图 / 少内容 | 正文图异步未加载完；或懒加载列表尚未构建该区块 | 同上 |
| 图与页面不一致 | 走了 A（另写的卡片） | 改走 B |
